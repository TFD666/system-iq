OPEN SOURCE / PYTHON CLI

Turn a project idea into a structured system design.

A command-line tool sends your idea to a hosted pipeline. An LLM extracts the requirements, the Jev decision model makes the architecture calls, and a 13-section design gets written around them — then validated against them.

01 PIPELINE

How it works

Five stages, two models. The architecture choices are made by a decision model, not by the writer — and the finished design is checked back against them.

05 PRIVACY

Privacy

  • Your idea is sent to Groq and OpenCode (both US) to generate the design.
  • Groq: zero data retention is enabled in the account settings for this demo.
  • OpenCode free tier: may use submitted text to improve their service.
  • System IQ redacts obvious secrets, keeps your design in memory up to 60 minutes so you can download it, then deletes it. Nothing is written to disk. Only counts are logged.
Do not enter secrets, personal data, or confidential company info.

On first run, the CLI prints a welcome message and creates one marker file in your config folder. No personal data is stored.

06 LIMITS

Honest limits

  • Free-tier rate limits make designs shorter and slower (~3 minutes).
  • This is a portfolio demo with daily capacity caps, not a service.
  • Evaluation: one rater, six ideas — small enough to be directional, not conclusive.
  • After a quiet period the first request takes about a minute while the server wakes.
